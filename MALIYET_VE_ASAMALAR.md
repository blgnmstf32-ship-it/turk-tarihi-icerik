# En düşük maliyet stratejisi

## Başlangıç sürümü (hazır): 0 TL zorunlu ücretli API
- 20 ücretli yapay zekâ hesabı **yok**; 20 görev modülü tek Python çalıştırıcısında.
- Yazı, altyazı yerine yazılı sahneler ve görsel şablonlar ücretsiz üretilir.
- FFmpeg ile sessiz MP4 oluşturulur; müzik ve gerçek seslendirme ekli değildir.
- GitHub Actions özel depo ücretsiz kullanım kotası içinde çalışabilir; kota bitiminde maliyet oluşabilir.
- ChatGPT/Codex aboneliği, internet erişimi, cihaz masrafı ve insan editör zamanı bu 0 TL ifadesine dahil değildir.

## Sonraki sürüm için önerilen bütçe kilitleri
1. Günlük en fazla 1 içerik denemesi; aynı konuyu tekrarlayan üretimleri engelle.
2. Metin ve tarih teyidi ücretsiz kaynak arşivi üzerinde kalsın.
3. Görsel için önce düşük maliyetli şablon ve lisansı uygun stok/özgün çizim.
4. Yalnızca en iyi senaryolar için ücretli AI video kullan.
5. Yüksek maliyetli üretimde saniye ve yeniden deneme sınırı uygula.
6. Harcama sınırını API sağlayıcısının kontrol panelinden ayrıca belirle.

**Önerilen geçiş:** 0 TL API taslak sistemi → 200–500 TL aylık deneysel görsel/ses → ölçülmüş başarıdan sonra hareketli AI video bütçesi. Bu rakamlar harcama hedefidir, bir sağlayıcının kesin paket fiyatı değildir.
